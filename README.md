# Estudos de Front-end

Repositório de estudos práticos sobre desenvolvimento de interfaces web, organizado por tecnologia e por etapa de aprendizado.

## Conteúdo

- HTML: estrutura semântica e fundamentos da web
- CSS: estilização, layouts e responsividade
- JavaScript: linguagem, DOM e interatividade
- React: componentes e construção de interfaces
- TypeScript: tipagem aplicada ao desenvolvimento front-end
- Roadmaps e materiais de apoio
- Projetos práticos para consolidação dos conceitos

## Estrutura

```text
01-html/
02-css/
03-javaScript/
04-react/
05-typescript/
06-roadmaps/
07-projetos/
```

Cada diretório reúne exemplos e exercícios independentes. Consulte os arquivos de cada módulo para acompanhar o conteúdo correspondente.

## Como utilizar

Clone o repositório e navegue até o exemplo desejado. Projetos estáticos podem ser abertos diretamente no navegador; exemplos com ferramentas próprias devem ser executados conforme as instruções presentes em seus diretórios.

```bash
git clone https://github.com/orlandoconceicao/frontend.git
cd frontend
```
